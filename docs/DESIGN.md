# 차경 디자인 가이드

## 방향

현대적인 동양풍 티룸. 밝은 원목과 백자, 자연광, 넓은 여백을 중심으로 하며 전통 문양을 과도하게 사용하지 않는다. 장난감 같은 부드러운 로우폴리 형태를 사용한다.

## 색상

- 미색 `#F5F2EA`
- 백자 `#FAFAF7`
- 세이지 `#B5C7A7`
- 짙은 세이지 `#566B58`
- 호두 원목 `#8B6B52`
- 먹색 `#27312E`
- 페일 핑크는 토끼 귀와 작은 포인트에만 사용

## 공간

- 실내: 3×2 배열의 낮은 찻상 여섯 개, 백색 벽, 큰 채광창
- 정원: 돌길, 대나무, 작은 수공간과 대기 여백
- 실내와 정원은 문이나 로딩 없이 한 장면으로 연결
- 카메라는 토끼 뒤쪽 위에서 바라보며 회전·확대할 수 있다.

## 토끼

눈·코·팔다리 묘사를 최소화한 둥근 체형. 흰색, 검정, 회색, 갈색, 크림, 얼룩 여섯 변형을 제공한다. 걷기, 앉기, 우리기, 마시기, 꾸벅 인사를 그룹 회전과 위치 보간으로 표현한다.

## UI

- 3D 장면을 가리지 않는 반투명 백자 패널과 둥근 캡슐형 컨트롤
- 데스크톱 차 선택은 오른쪽 패널, 모바일은 아래쪽 시트
- 접속 인원, 현지 시간대, 연결 상태를 상단에 표시
- 이름표와 행동 버튼은 작은 크기를 유지하고 채팅창은 두지 않는다.
- 키보드 포커스, 충분한 대비, `prefers-reduced-motion`을 지원한다.

## 조명

- 낮: 중성 자연광과 옅은 녹색 안개
- 해질녘: 낮은 주황빛 방향광
- 밤: 청록빛 환경광, 실내의 따뜻한 점광원과 네 개의 촛불
- 테스트 쿼리 `time=day|dusk|night`로 강제 전환
