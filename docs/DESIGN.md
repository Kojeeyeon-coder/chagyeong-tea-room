# 차경 디자인 가이드

## 방향

현대적인 동양풍 티룸. 밝은 원목과 백자, 자연광, 넓은 여백을 중심으로 하며 전통 문양을 과도하게 사용하지 않는다. 장난감 같은 부드러운 로우폴리 형태를 사용한다.

## 색상

- 미색 `#F5F2EA`
- 백자 `#FAFAF7`
- 세이지 `#B5C7A7`
- 짙은 세이지 `#566B58`
- 호두 원목 `#8B6B52`
- 먹색 `#27312E`
- 페일 핑크는 토끼 귀와 작은 포인트에만 사용

## 공간

- 실내: 다구 간격을 넓힌 4인 합석 찻상 네 개와 좌우 벽의 1인 찻상 네 개, 백색 벽, 큰 채광창
- 정원: 돌길, 대나무, 작은 수공간과 대기 여백
- 실내와 정원은 문이나 로딩 없이 한 장면으로 연결
- 이동 중에는 차실의 벽과 동선을 읽기 쉬운 후방 구도를 유지한다. 착석이 완료되면 토끼 얼굴과 다구를 바라보는 전면 집중 구도로 부드럽게 전환하며, 정지 상태에서는 회전·확대할 수 있다.

## 토끼

눈·코·팔다리 묘사를 최소화한 둥근 체형. 흰색, 검정, 회색, 갈색, 크림, 얼룩 여섯 변형을 제공한다. 걷기, 앉기, 우리기, 마시기, 꾸벅 인사를 그룹 회전과 위치 보간으로 표현한다.

## UI

화면 하단 중앙에 `인사하기 · 자리에 앉기/일어나기 · 차 우리기 · 차 마시기` 네 액션을 고정한다. 차 선택은 `차 우리기`를 처음 눌렀을 때 보조 패널로 열리고, 한 잔을 마친 뒤 `한 잔 더`에서도 다시 열어 다른 차를 고를 수 있다. 의식 시작과 함께 패널은 닫혀 3D 애니메이션을 가리지 않는다. 우리기는 준비·우림·따르기를 짧은 자동 시퀀스로 연결하고, 마시기는 별도 탭으로 분리한다. 상단의 소리 버튼은 기본 OFF이며 사용자의 직접 입력으로만 재생을 시작한다. 배경음은 낮은 바람결 위에 한국 오음계에 가까운 짧은 선율을 느린 호흡으로 반복하며, 공간음만 이어지는 긴 정적을 피한다.

실내는 다다미 질감의 자리 구획, 쇼지 격자창, 노출 목재 보, 족자, 다기 선반, 화분과 한지 조명으로 밀도를 보강한다. 숯빛 화로와 탕관, 반복해서 피어나는 김을 두어 실제 다실의 온기를 더한다. 잎차는 다관·개완이 투명 유리 숙우로 기울고 차의 수색이 보이는 숙우가 다시 찻잔으로 기우는 2단 따르기 동작을 쓴다. 자사호는 둥글고 낮은 서시호 비례로 만들고, 말차는 연두색 액체와 회전하는 거품, 차선의 빠른 좌우·앞뒤 격불 동작을 사용하며 마실 때는 기존 다완을 들어 올린다.

다구 세트는 좌석의 회전값을 그대로 따라가 항상 토끼 기준 좌우로 펼쳐진다. 1인석에서는 상판 중앙에, 합석상에서는 각 좌석 방향의 중앙 축에 두어 세로 줄이나 가장자리 쏠림을 피한다. 말차 차선은 원을 그리지 않고 짧은 V자 왕복 궤적을 반복한다.

- 3D 장면을 가리지 않는 반투명 백자 패널과 둥근 캡슐형 컨트롤
- 데스크톱 차 선택은 오른쪽 패널, 모바일은 아래쪽 시트
- 접속 인원, 현지 시간대, 연결 상태를 상단에 표시
- 이름표와 행동 버튼은 작은 크기를 유지하고 채팅창은 두지 않는다.
- 키보드 포커스, 충분한 대비, `prefers-reduced-motion`을 지원한다.

## 조명

- 낮: 중성 자연광과 옅은 녹색 안개
- 해질녘: 낮은 주황빛 방향광
- 밤: 청록빛 환경광, 실내의 따뜻한 점광원과 네 개의 촛불
- 테스트 쿼리 `time=day|dusk|night`로 강제 전환
