# 차경(茶境) Product Requirements

버전 0.2 · 2026-10-31

## 비전

누구나 토끼가 되어 차를 마시며 잠시 쉬어갈 수 있는 온라인 다실. 가입과 복잡한 설정 없이 들어와 다른 이용자들과 조용히 공간을 공유한다.

## 핵심 사용자 여정

1. URL에 접속하면 토끼 외형과 시적인 한국어 이름을 자동 배정받는다.
2. 실내 다실과 작은 정원을 클릭·터치로 산책한다.
3. 하단의 `자리에 앉기`를 눌러 가장 가까운 빈 방석으로 이동해 앉는다.
4. 6대 다류와 말차 중 하나, 네 종류 다구 중 하나를 선택한다.
5. 하단의 `차 우리기`로 준비·우리기·따르기를 자동 진행하고, `차 마시기`로 마지막 동작을 직접 시작한다.
6. 다른 토끼와 함께 머물고 꾸벅 인사한 뒤 자리에서 일어난다.

## 기능 요구사항

- PC·모바일 최신 브라우저와 반응형 UI
- 여백 많은 절차형 로우폴리 3D 실내·정원 한 공간
- 6종 토끼 외형과 방 안에서 중복되지 않는 이름의 균등 무작위 배정
- `main` 방 최대 20명, 1.5초 이내 갱신되는 근실시간 presence
- 4인 합석 찻상 4개와 벽 쪽 1인 찻상 4개로 총 20석, 원자적 좌석 점유
- 착석 전 `혼자 앉기`와 `합석하기`를 선택하며, 합석은 이미 이용자가 있는 빈 찻상을 우선한다.
- 같은 합석 찻상에서는 채팅 없이 `차 요청하기`와 `차 따라주기`의 짧은 상태만 공유한다.
- 녹차·백차·황차·청차·홍차·흑차·말차
- 백자 개완·자사호·한국식 다관·말차 다구의 고유한 간결 연출
- 잎차는 다관·개완에서 숙우로, 숙우에서 찻잔으로 두 번 나누어 따르는 흐름을 보여 준 뒤 마실 수 있다.
- 말차는 연두빛 거품과 빠른 차선 왕복 동작으로 격불하고, 별도 찻잔을 만들지 않고 다완을 그대로 들어 마신다.
- 숙우는 투명 유리로 표현하고 선택한 차의 수색을 내부 액체로 보여 준다. 자사호는 둥글고 낮은 서시호 비례를 따른다.
- 기기 현지 시각에 따른 낮·해질녘·밤 조명과 야간 촛불
- 꾸벅 인사, 재연결 표시, WebGL 미지원 안내
- 인사하기·자리에 앉기·차 우리기·차 마시기를 항상 같은 위치에서 실행하는 하단 4탭 액션 바
- 다도 진행 중 토끼와 찻상으로 카메라를 당기고, 앞발·몸통·찻잔 동작을 강조하는 집중 연출
- 이동과 다도 중에는 토끼 앞모습을 기본으로 보여 주며, 이용자는 정지 상태에서 자유롭게 카메라를 회전한다.
- 한 잔을 마친 뒤 `한 잔 더`를 누르면 차와 다구 선택 화면을 다시 열어 다른 차로 바꿀 수 있다.
- 고요한 바람·저음·풍경 소리로 구성한 배경음을 기본 OFF로 제공하고, 화면 상단에서 직접 켜고 끈다.

## 성공 지표

- 별도 입력 없이 목표 5초 이내 입장
- 서로 다른 두 기기의 위치·행동이 목표 2초 이내 표시
- 좌석 선택부터 한 잔 완료까지 1분 이내
- 일반 PC 60fps, 중급 모바일 30fps 목표
- 20명 상태에서 좌석 중복 점유 없음

## 오류와 복구

- 방이 가득 차면 만실 메시지와 재시도 버튼을 제공한다.
- 연결이 끊기면 로컬 산책은 유지하되 좌석·행동 변경을 제한한다.
- heartbeat가 10초 이상 없으면 이용자와 좌석을 만료한다.
- 점유 경쟁에서 진 이용자에게 다른 토끼가 먼저 앉았다는 메시지를 표시한다.
- 이동 불가 지점은 경로를 만들지 않고 짧은 안내를 표시한다.

## MVP 제외

회원가입, 채팅, 차 건네기, 외형·액세서리 선택, 과금, 음성 대화, 친구 초대, 수동 방 선택, 여러 맵, 상세한 온도·우림 시간 시뮬레이션, PWA 설치와 오프라인 플레이.
